A complete Full-Stack Task Management system featuring a robust, production-ready RESTful API built with **ASP.NET Core** and an interactive, visually stunning frontend created entirely by **AI**.

## 🚀 Overview
This project serves as a comprehensive system for managing daily tasks and users. It demonstrates backend engineering best practices like the **Repository Pattern**, **DTOs**, **Clean Architecture**, and **Role-Based Authorization**. 

Additionally, it includes a modern **Single Page Application (SPA)** frontend featuring a Glassmorphic Dark Theme, showcasing how AI can be leveraged to rapidly build and integrate beautiful user interfaces with complex backend systems.

## ✨ Key Features
- **Secure Authentication:** JWT-based login and registration with strong `BCrypt` password hashing.
- **Role-Based Access Control (RBAC):**
  - **Users:** Can only view, create, edit, and delete their own tasks.
  - **Admins:** Can manage all users, assign tasks to anyone, and view system-wide data.
- **Full CRUD Operations:** Complete task management (Pending, InProgress, Completed, Cancelled).
- **AI-Generated Frontend:** A responsive, interactive UI built with HTML5, CSS3, and Vanilla JavaScript (No frameworks), completely generated by AI.
- **Database Management:** Uses **Entity Framework Core (Code First)** with **SQLite** for zero-configuration local development.
- **API Documentation:** Integrated **Swagger UI** for easy endpoint testing.

## 🛠️ Technologies Used
- **Backend:** ASP.NET Core Web API, C#
- **Database:** SQLite, Entity Framework Core
- **Security:** JWT (JSON Web Tokens), BCrypt.Net
- **Architecture:** Repository Pattern, Dependency Injection, DTO Pattern
- **Frontend:** HTML, CSS (Glassmorphism), Vanilla JavaScript (AI-Generated)
- **Tools:** Swagger, Postman, Git

## ⚙️ Getting Started

### Prerequisites
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download) (or later)

### Installation & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/task-manager-api.git
   cd task-manager-api
   ```
2. Run the application (The SQLite database will be created and seeded automatically):
   ```bash
   dotnet run --project "src/TaskManagerAPI/TaskManagerAPI.csproj"
   ```
3. Open your browser and navigate to:
   - **Interactive UI:** `http://localhost:5071`
   - **Swagger Documentation:** `http://localhost:5071/swagger`
